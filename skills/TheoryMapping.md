# 理论框架映射技能

## 功能概述

模式3扩展技能之一。在 DeepResearch 完成核心探索后，本技能自动识别问卷所属研究领域，加载对应理论库，将数据发现与经典理论进行系统映射。

## 领域自适应机制

1. **领域识别**：基于问卷标题、列名、关键词，LLM 判断主题领域
2. **理论库加载**：从内置多领域理论库（theory_knowledge_base.json）加载对应理论
3. **映射评估**：对每个理论评估数据的支持/反驳/扩展/中性关系

## 支持领域

| 领域 | 代表理论 | 说明 |
|------|---------|------|
| 教育技术 | TAM, UTAUT, TPACK, SAMR, CoI (探究社区模型) | 侧重技术接受与整合 |
| 教育心理学 | 自我决定理论, 建构主义, 认知负荷, 心流理论, 成就目标理论, 归因理论 | 侧重学习心理与动机 |
| 社会心理学 | 社会认知理论, 计划行为理论, 社会认同理论, 社会交换理论, 精细加工可能性模型 (ELM) | 侧重个体-社会互动，承袭原“社会科学”的核心 |
| 社会学 | 社会资本理论, 社会网络理论, 结构化理论, 场域理论 (布迪厄), 框架理论 (戈夫曼) | 侧重结构、网络与制度，独立于心理学视角 |
| 组织行为 | 变革管理, JD-R, 创新扩散, 组织公正理论, 目标设置理论, 交易型/变革型领导 | 侧重职场行为与管理系统 |
| 健康行为 | 健康信念模型, 跨理论模型, 保护动机理论, 社会生态模型 | 侧重健康改变阶段与风险认知 |
| 媒介传播 | 使用与满足, 议程设置, 涵化理论, 沉默的螺旋, 数字鸿沟 | 侧重传播效果与媒介效应 |
| 行为经济学 | 前景理论, 助推理论, 双系统理论, 心理账户 | 侧重非理性决策与选择架构 |
| 政治与政策研究 | 多源流模型, 倡导联盟框架, 间断均衡理论, 政策反馈理论 | 侧重政策过程与集体行动 |
| 文化人类学/跨文化研究 | 文化维度理论 (霍夫斯泰德), 文化脚本, 阈限理论, 实践共同体 | 侧重文化意义与跨群比较 |
| 环境与空间心理学 | 注意力恢复理论, 场所依恋, 亲环境行为模型, 防御空间理论 | 侧重人-环境关系与空间设计 |
| 信息与知识管理 | 信息觅食理论, 信息采纳模型, SECI知识转化模型, 技术接受与使用整合 (UTAUT 亦可复用) | 侧重信息行为与知识流动 |

## 输出

- `theory_mapping.json`: 结构化映射结果
- `theory_mapping_report.md`: 可读报告

## 论文映射

- 体现系统的"理论敏感度"——从数据到理论的跃迁
- 支持论文"理论贡献"章节的撰写
